# Checklist Materi Rebranding Website Nalara Karya Indonesia

Dokumen ini menjadi acuan pengumpulan materi untuk mengganti identitas website dari SDK (Solusi Digital Kita) menjadi Nalara Karya Indonesia.

Brief gambar yang tersedia saat ini cukup untuk menentukan arah awal, tetapi belum dapat digunakan sebagai aset produksi. Tim perlu mengirimkan file logo asli, data perusahaan, konten final, serta media pendukung sebelum implementasi dimulai.

Informasi berikut dibaca dari brief gambar dan masih perlu dikonfirmasi oleh pemilik merek atau desainer.

## Prioritas 1: Materi wajib sebelum implementasi

### 1. Paket logo

Siapkan file berikut:

- [ ] Logo horizontal untuk latar terang dalam format SVG
- [ ] Logo horizontal putih untuk latar gelap dalam format SVG
- [ ] Logo mark atau simbol N tanpa tulisan dalam format SVG
- [ ] Logo monokrom hitam dalam format SVG
- [ ] Logo monokrom putih dalam format SVG
- [ ] File master desain dalam format AI, EPS, atau PDF
- [ ] Versi PNG transparan dengan resolusi tinggi

Nama file yang disarankan:

```text
logo-nalara-horizontal-dark.svg
logo-nalara-horizontal-white.svg
logo-nalara-mark.svg
logo-nalara-monochrome-black.svg
logo-nalara-monochrome-white.svg
logo-nalara-master.ai
```

### 2. Ikon website

- [ ] `favicon.svg`
- [ ] `favicon-32x32.png`
- [ ] `favicon-192x192.png`
- [ ] `apple-touch-icon.png`, minimal 180 x 180 piksel
- [ ] Ikon kotak tanpa tulisan untuk shortcut atau aplikasi

### 3. Panduan merek

Siapkan brand guideline dalam format PDF atau tautan Figma yang dapat diakses. Dokumen minimal berisi:

- [ ] Kode warna resmi dalam HEX dan RGB
- [ ] Nama font resmi
- [ ] Daftar weight font yang digunakan
- [ ] Aturan jarak aman logo
- [ ] Ukuran minimum logo
- [ ] Penggunaan logo pada latar terang dan gelap
- [ ] Penggunaan tagline
- [ ] Contoh penggunaan logo yang tidak diperbolehkan
- [ ] Filosofi nama Nalara
- [ ] Filosofi simbol N
- [ ] Karakter komunikasi merek

### 4. Data resmi perusahaan

- [ ] Nama legal perusahaan
- [ ] Nama yang ditampilkan di website
- [ ] Bentuk badan usaha, jika perlu ditampilkan
- [ ] Tahun berdiri, hanya jika akan dipublikasikan
- [ ] Alamat resmi
- [ ] Email perusahaan
- [ ] Nomor telepon
- [ ] Nomor WhatsApp
- [ ] Jam operasional
- [ ] Domain website final
- [ ] Tautan Google Maps
- [ ] LinkedIn
- [ ] Instagram
- [ ] YouTube
- [ ] Media sosial lain yang aktif

Email dengan domain perusahaan lebih disarankan daripada alamat Gmail. Contoh format yang perlu diputuskan:

```text
hello@domain-nalara.com
info@domain-nalara.com
support@domain-nalara.com
```

Contoh di atas hanya menunjukkan format. Tim harus mengisi domain dan alamat yang benar.

## Prioritas 2: Konten website

Konten perlu disiapkan dalam Bahasa Indonesia dan Bahasa Inggris. Jika terjemahan Inggris belum tersedia, tandai bagian tersebut sebagai belum final.

### Beranda

- [ ] Headline utama
- [ ] Subheadline
- [ ] Deskripsi singkat perusahaan
- [ ] Tombol aksi utama dan tujuan tautannya
- [ ] Tombol aksi kedua, jika diperlukan
- [ ] Daftar produk atau layanan yang ingin ditonjolkan
- [ ] Gambar hero atau screenshot produk

### Tentang Kami

- [ ] Cerita perusahaan
- [ ] Alasan perusahaan didirikan
- [ ] Visi
- [ ] Misi
- [ ] Nilai perusahaan
- [ ] Penjelasan makna nama Nalara
- [ ] Filosofi logo
- [ ] Profil pendiri atau tim, jika akan ditampilkan
- [ ] Foto tim asli, jika akan ditampilkan

### Produk dan layanan

Konfirmasikan apakah produk berikut tetap menjadi bagian dari Nalara:

- [ ] Human Resource Management System
- [ ] Learning Management System
- [ ] Psikotes Management System
- [ ] Point of Sales
- [ ] Hotel Management System
- [ ] Web dan Mobile Apps Custom

Gunakan format berikut untuk setiap produk:

```text
Nama produk:
Status produk:
Target pengguna:
Masalah yang diselesaikan:
Deskripsi singkat:
Deskripsi lengkap:
Fitur utama:
Platform yang didukung:
Integrasi yang tersedia:
Screenshot asli:
Tautan demo, jika ada:
Tombol aksi yang diinginkan:
```

Status produk harus menggunakan informasi yang benar, misalnya siap digunakan, tersedia untuk demo, dapat dikustomisasi, atau masih dikembangkan.

### Kontak

- [ ] Alamat yang akan ditampilkan
- [ ] Email tujuan formulir
- [ ] Nomor telepon
- [ ] Nomor WhatsApp
- [ ] Jam operasional
- [ ] Lokasi Google Maps
- [ ] Pesan konfirmasi setelah formulir terkirim
- [ ] Pihak yang menerima dan menindaklanjuti pesan

## Prioritas 3: Foto dan media

- [ ] Foto tim asli
- [ ] Foto kantor

- [ ] Judul SEO
- [ ] Deskripsi SEO
- [ ] Kata kunci utama

- [ ] Beranda

## Dokumen legal

- [ ] Privacy Policy
- [ ] Terms of Service, jika diperlukan

- [ ] Kebijakan cookie, jika website menggunakan cookie non-esensial

- [ ] Logo klien

## Catatan teknis untuk implementasi

Rebranding lengkap tidak hanya menyentuh konten di folder `source/`. Implementasi juga memerlukan izin untuk mengganti:

- `image/logo/`, untuk logo, favicon, dan ikon Nalara
- `page.config.json`, untuk judul halaman dan metadata SEO

Jika perubahan tetap dibatasi hanya pada folder `source/`, logo produksi dan metadata SEO tidak dapat diganti secara lengkap melalui alur build yang sekarang.
